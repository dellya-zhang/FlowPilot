# 政策知识库：检索增强摘录回答

## 使用

启动本地后端后，在右侧“政策知识库”输入“退款政策是什么”“会员有什么权益”或“全量名单排重”。回答包含原文、文件名、章节和片段 ID，无依据时返回未命中提示。该入口独立于客服审核流程，不创建、确认或取消业务操作。

默认不调用模型。勾选“使用已配置模型筛选依据”后，模型从检索片段中选择可回答问题的证据，服务端校验 ID 后返回原文。需要先配置现有模型 Provider；Mock 模式保持免费摘录。云模型会接收问题与召回片段；选择 local 才连接本机推理。

## 链路

本地 Markdown → 按标题与长度分块（280 字符、40 字符重叠）→ 中文二元词组 / 英文词切分 → BM25 Top-3 → 可选模型证据选择 → 片段 ID 校验 → 引用原文 / 拒答。

当前是稀疏检索与抽取式回答，不包含 Embedding、向量数据库、稀疏/稠密混合检索或 Cross-Encoder 重排；模型证据选择也不等于专用重排模型。无模型模式属于检索摘录，不声称运行了大模型生成。

## 接口

```bash
curl -X POST http://127.0.0.1:8000/api/v1/knowledge/answer \
  -H 'Content-Type: application/json' \
  -d '{"question":"退款政策是什么","use_model":false}'
```

- `POST /api/v1/knowledge/search`：相同请求体，返回检索片段与 BM25 分数；不调用模型。
- `POST /api/v1/knowledge/answer`：返回 answer、citations、abstained、mode 和 corpus_version。
- 设置 ACCESS_TOKEN 时，两者都需要 Bearer 认证。

## 更新与运行边界

文档在 `app/knowledge/*.md`，只收录合成演示政策。更新文件后需重启所有 worker；各 worker 应部署同一版本。片段 ID 基于来源、标题、位置与文本哈希，语料版本由片段 ID 派生。未提供上传、远程 URL 抓取、在线重建索引或租户知识库。

限制为 100 个文件、单文件 256 KiB、2000 个片段、问题 500 字符；不接受符号链接。模型调用共享原有进程信号量和同机预算账本；容量不足返回 429，模型异常返回不含内部细节的 502。回答使用原文和 textContent 渲染，不执行文档中的指令，也不允许模型授权业务写操作。

BM25 分数不是置信度；词面命中可能无关，同义改写也可能漏召回。无模型模式仅在无词面命中时拒答，不能保证语义层面的拒答正确性。原文可信度依赖维护者审核；引文存在不等于政策真实有效。扩大语料前应补语义相关性评测、版本管理与权限过滤。

## 验证

`pytest tests/test_knowledge.py -q` 覆盖分块重叠、稳定 ID、五类政策检索、无命中拒答、引用溯源、模型证据选择、伪造引用拒绝、预算记账、模型拒答、故障释放并发许可和容量不足。

模型契约测试使用本地 MockTransport，不发生真实付费调用；五类样例只验证当前演示语料，不能推导线上召回率或回答质量。

GitHub Pages 仅显示此入口的本地启动提示，不模拟检索与模型结果。
