# 用户操作指南

## 选择体验方式

| 方式 | 入口 | 数据与费用 |
|---|---|---|
| 在线交互预览 | https://dellya-zhang.github.io/temp/ | 浏览器模板模拟、localStorage；不调用后端或模型 |
| 本地完整Mock | 按README启动后访问localhost:8000 | 真实Python/SQL/LangGraph链路，模型为模板，无API费用 |
| 本地DeepSeek | .env中切换AI_PROVIDER并重启 | 真实营销草稿生成，受调用和预算上限约束 |

在线版展示操作方式，不冒充真实后端运行。A/B在线抽样使用确定性演示名单，完整后端使用固定种子抽样。实验转化均由演示按钮输入，不是实际营销回流。

## 页面区域

- 左侧创建任务：填写目标、选择人群、设置预算；下方可切换历史任务。
- 中间方案区域：等待候选，阅读标题、文案及理由，然后审批。评分只是规则演示，不代表转化预测。
- 中间实验区域：双臂试点、模拟转化、人工晋级。普通审批和实验晋级是不同路线。
- 中间执行事件：完整模式是持久化业务事件，通过SSE或令牌模式轮询更新；静态预览模拟事件并轮询本地状态。
- 右侧客服：政策咨询、业务申请、确认和取消，展示历史。

## 单方案与实验不能混用

普通路线：生成 → 审批 → 导出试点 → 全量排重。

实验路线：生成 → 创建双臂 → 模拟转化 → 人工晋级 → 全量排重。

实验建立后，不应普通审批；晋级后不应重新创建第三批普通试点。完整后端会返回409阻止这类操作。

## 下载结果

产物显示pilot/full、行数和下载按钮，CSV列为customer_id、segment、region。完整后端下载时检查SHA256，文件丢失或被篡改会返回503，不返回坏数据。在线演示CSV在浏览器生成，不需要访问任何客户系统。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 按钮灰色 | 尚未到对应阶段；先等待生成、审批或完成试点 |
| 409 | 状态冲突、重复审批或混用实验路线；刷新任务并按当前阶段操作 |
| 422 | 输入长度、预算、候选归属或其他字段不合法 |
| 429 | 请求过快或当前worker任务容量已满，稍后重试 |
| 503 | 数据库/存储暂不可用或文件完整性失败，检查依赖后重试 |
| 候选不足3套 | 分支异常被隔离；查看事件，剩余合法候选仍可人工检查 |
| 全部生成失败 | 检查Provider配置、API额度、网络和预算上限；不要反复盲目请求 |
| 客服说没有真实订单 | 这是当前实现边界，不会编造订单结果 |
| 在线预览数据异常 | 顶部重置演示后刷新；只清理本演示数据 |
| Pages尚在部署 | 查看仓库Actions中的Interactive demo工作流状态 |

## 本地令牌保护

.env可以设置ACCESS_TOKEN，页面右侧“访问令牌”输入同值后保存。它仅为单用户入口保护，没有租户或对象级权限。不要把DEEPSEEK_API_KEY当作页面访问令牌填写。

## 数据保存与隐私

静态在线预览只存当前浏览器。完整后端默认保存SQLite文件和本地CSV；不要上传真实客户信息来做演示。本仓库不包含真实Key、私人PDF、实习内部代码或真实投放服务。
