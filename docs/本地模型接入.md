# 本地模型接入与连接测试

FlowPilot 的“模型连接”位于工作台右侧。在线Pages页面只做交互模拟，不扫描或请求你的localhost，也不接收模型API Key。请从本机运行的工作台使用此功能。

## 先启动本机工作台

```powershell
git clone https://github.com/dellya-zhang/temp.git
cd temp
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
Copy-Item .env.example .env
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

已有.env时保留原文件，不重复覆盖。访问 http://127.0.0.1:8000/ 。默认Mock不调用任何模型；可以先点“测试本机连接”验证页面与本地后端。

## 方式一：本机后端调用DeepSeek

在本机.env中配置：

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=替换为本机保存的真实Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
LLM_MAX_TOKENS=600
LLM_MAX_CALLS=18
LLM_BUDGET_CNY=10
```

重启后端，在本地页面点击模型连接区“刷新”，确认配置已读取，再显式点“测试本机连接”。它只发送固定的虚构会员积分介绍需求，不提交左侧表单或客户资料。每次测试最多调用一次，无自动重试；真实生成活动时仍使用左侧业务需求。

**本地中转不等于本地推理**：API Key由本机后端读取，但提示词仍发送至云端供应商。模型Key不经过网页表单、localStorage或sessionStorage，也不返回到浏览器。可选ACCESS_TOKEN是工作区访问令牌，与模型Key不同；页面仅在当前内存中保留该访问令牌，刷新页面需重新输入。

## 方式二：完全连接本机推理服务

先自行安装并启动兼容OpenAI Chat Completions格式的本地模型服务，例如已有Ollama，再使用服务中已安装的模型名称配置：

```dotenv
AI_PROVIDER=local
LOCAL_MODEL_BASE_URL=http://127.0.0.1:11434/v1
LOCAL_MODEL_NAME=替换为已安装模型名称
LOCAL_MODEL_API_KEY=
```

Ollama本机API通常不要求Key；若你的本机服务要求认证，可只在.env填写LOCAL_MODEL_API_KEY。HTTP只允许在local Provider的回环地址使用，禁止将local模式指向外部主机。本机推理请求关闭环境代理继承。

模型需支持本项目使用的JSON对象输出，并生成title、message、reasoning三个非空字符串。实际兼容能力取决于模型与服务；本次测试已用受控适配器验证该协议，但没有下载或启动真实本地大模型。不会为了演示自动安装大型模型或替你选择云端服务。

参考：[Ollama官方兼容接口](https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx)、[本机API认证说明](https://github.com/ollama/ollama/blob/main/docs/api/authentication.mdx)。

## 本地接口

`GET /api/v1/local-model`：返回Provider、模型名、是否配置、调用名额、保守预算占用，不返回密钥、文件路径或供应商认证头。

`POST /api/v1/local-model/test`：不接受请求体；必须带X-Local-Model-Test头；使用固定测试提示词，返回结构化输出示例和耗时。

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/local-model
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/local-model/test -Headers @{'X-Local-Model-Test'='1'}
```

若设置了ACCESS_TOKEN，调用时还需Authorization: Bearer加对应令牌。本地网页会在用户输入工作区访问令牌后附加此头；不要填写模型Key。

## 安全限制与失败提示

- 示例默认不允许跨源访问；完整前端由同一个本地后端提供。已有.env若不需要分离开发，可将CORS_ORIGINS置空。
- 本地页面响应禁止iframe嵌入，诊断响应使用no-store，避免缓存配置摘要。
- 诊断仅接受回环peer及回环Host；浏览器Origin存在时必须与页面同源，拒绝null和跨来源请求。
- 网页不能指定代理目标、模型、密钥或任意提示词，避免接口变成开放转发代理。
- 预算和输出上限与正常Provider共享；503表示预算记录不可用，429表示调用或预算上限，504表示超时，502表示连接或结构化输出不合格。
- 超时不代表免费，无法确认usage时保留预算预留。预算占用不是供应商实际账单；本地推理也复用调用名额保护，并不代表产生API费用。
- 用户授权的本机日志目前保留历史调用，不因重启或刷新重置。不要删除预算文件绕过上限。
- 确保本机后端和模型服务可信；这些访问控制不构成对本机恶意软件或浏览器扩展的绝对安全保证。
