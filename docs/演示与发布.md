# 演示与发布

## 5 分钟演示

1. Python 3.11+ 安装 `pip install -e ".[dev]"`，运行 `uvicorn app.main:app`。
2. 打开 localhost:8000，创建会员权益活动，观察候选与执行事件。
3. 路线 A：审批一套方案 → 试点 CSV → 全量 CSV。
4. 路线 B：新建任务 → A/B 试点 → 记录模拟转化 → 人工晋级 → 全量交付。
5. 客服输入“退款政策是什么”，再输入“我要退款”，确认审核，检查会话历史。
6. 下载 CSV，对照试点与全量 ID 集合，解释 consent 过滤和排重。

## 部署选择

- 零基础设施：SQLite + 本地文件 + Mock；用于演示、学习和面试复现。
- Docker Compose：PostgreSQL + Redis + MinIO 的配置已提供，但本次机器无 Docker 命令，尚未运行验收。
- 可选 OpenAI 模式：设置 AI_PROVIDER、OPENAI_API_KEY；本次无密钥，未做真实调用或质量评估。

默认端口绑定 127.0.0.1，公开部署须提供 TLS、凭据管理和身份/权限隔离；共享 ACCESS_TOKEN 只适用于单用户演示入口。

## 运维

- 健康检查 `/api/v1/health`；请求带 X-Request-ID 响应头，访问日志可关联请求。
- 日常备份 SQLite 文件（停止服务后复制）及 artifacts 目录；PostgreSQL 使用 pg_dump，MinIO 保持相应对象备份。
- 配置文件变更后重启服务；不要在运行中删除数据库。
- 当前采用 create_all：修改已有表结构需要自行迁移，尚未提供 Alembic。
- 后台任务进程内执行，启动恢复 GENERATING 任务，单 worker 使用；正常退出等待后台任务完成。
