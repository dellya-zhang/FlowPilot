## 复现并修复的主要问题

1. **输入无效仍建任务。** 空白和NUL原来可通过长度检查；现在输入先去空白，拒绝控制字符和多余字段。
2. **取消泄漏子任务。** 原父任务被取消后，两个模型调用仍运行；现在显式持有子task，finally中cancel并gather。
3. **容量检查竞态。** 原先检查len(tasks)后再await数据库，多请求同时穿过；现在用锁预留pending admission，失败也释放名额。
4. **并发只限单活动。** 增加应用级model_slots信号量，候选同时受单活动和全局容量约束；仅限单进程。
5. **文件损坏未验证。** 下载和试点排重读取均检查SHA256，丢失/损坏返回503；文件写采用临时文件+原子replace。
6. **存储故障500。** 已知I/O和对象存储错误转换为可重试503，数据库事务回滚，不交付半成品。
7. **A/B流程被绕过。** 实验建立后禁止普通approve；晋级后禁止单独pilot导出，避免创建与两臂不一致的第三批试点。
8. **事件与状态分开提交。** queued、approved、pilot、completed及生成完成事件与对应状态在同一事务提交，减少客户端收到失败而状态已变化的窗口。
9. **SSE长期占数据库连接。** 路由存在性检查后释放事务，流式期间只在短查询时使用独立session。
10. **资源上限缺失。** API请求体64KiB、读取总时限10秒、模型响应64KiB、会话历史最多200条，避免基本的无限缓冲。
11. **错误分支输入。** 校验事件游标的范围及头长度，规则DSL拒绝不可哈希字段/算子，认证比较用bytes避免非ASCII字符串报错。
12. **预算数据可信度。** 对异常负Token用量不做负结算，而保留完整预留；并发预留严格限制本进程发送次数。

## 仍需考虑的问题（没有假称已经解决）

| 优先级 | 风险 | 当前影响 / 后续方向 |
|---|---|---|
| P1 | 多进程任务重复恢复 | 单进程有效；需队列认领、租约、fencing，才能多副本运行 |
| P1 | 预算日志的进程锁和文件原子性 | 不支持跨进程，进程在写日志时强杀可能截断；目前损坏即失败关闭，需数据库账本和事务 |
| P1 | 取消无法终止已发出的远程调用/线程 | task被取消不代表供应商不计费；to_thread写文件被取消时底层线程仍可能写完，可能留下孤立对象；需幂等键、对账及回收 |
| P1 | 单例共享令牌没有租户隔离 | 不能处理真实客户数据；需认证主体、对象级授权和审计 |
| P1 | 模型业务语义 | 拒绝说明仍可能成为候选，信息不足无完整澄清阶段；需产物类型和状态分支 |
| P2 | 生成恢复丢弃部分候选 | 重启重跑整次，可能重复模型费用；需持久化Checkpoint及副作用设计 |
| P2 | 慢对象存储时持有数据库写事务 | 线程化避免阻塞事件循环，但写锁仍占用；需拆物化任务、超时和产物提交协议 |
| P2 | SQLite单写及大恢复队列 | 本次突发通过不消除锁竞争；启动恢复批量创建任务未做分页调度，模型并发虽受限，task数量仍可能很大 |
| P2 | 跨数据库差异 | 未安装Docker，PG行锁、Redis故障、MinIO中断均未真实验证；本轮对象存储故障由适配层注入 |
| P2 | SSE长连接数量 | 已测40次断连，未测数小时慢消费者、数千连接或代理缓冲；需网关连接上限及重放窗口 |
| P2 | 只有存活检查 | /health不验证模型/存储/数据库全部可用；需独立readiness和依赖健康指标 |
| P2 | 输入接收时限不等于供应商总时限 | HTTPX timeout通常是分阶段无进展时限，候选外层wait_for才提供总执行限制 |
| P2 | 规则和实验统计 | 关键词误报、无真实归因/显著性/观察窗口，不能据此声称业务收益 |
| P3 | 长期数据增长和超大人群 | 列表最多100、历史200不等于数据库保留策略；导出仍整批内存构建，需分页、流式物化与清理策略 |
| P3 | 压缩炸弹和网络慢连接 | 当前JSON API无压缩解码功能，边缘网关仍需限制解压后大小、速率、TLS和连接数 |

P1指本项目后续工程化应优先解决的风险，不表示已经造成生产事故。
