# 快速验证

## 不装本地环境：GitHub Codespaces

1. 打开 [开发分支](https://github.com/dellya-zhang/FlowPilot/tree/feat/agent-runtime)，选择 Code → Codespaces → Create codespace on feat/agent-runtime。
2. 自动安装 Python 和 Node 依赖、编译 Vue，并启动 Mock 后端。终端出现地址后，打开 Ports 中的 8000，链接后补 /console/。确保端口可见性为 Private。
3. 新建营销活动，使用自定义输入、审批并下载 CSV。客服选择合成会员 1，查询订单和积分，输入“我要退款 FP-0001-A”并确认，检查本地审核工单。
4. 如需真实模型，在当前 Codespace 终端输入（密钥不会回显或写进源代码）：

```bash
read -rsp 'DeepSeek API key: ' DEEPSEEK_API_KEY; echo
export DEEPSEEK_API_KEY
bash .devcontainer/start.sh deepseek
```

也可以通过 GitHub Codespaces 的用户 Secrets 设置 DEEPSEEK_API_KEY 并授权该仓库，再执行上述启动命令（不需要 read）。刷新 /console/，新建文案比较活动或客服查询（启用模型）。只有真实调用成功才会有供应商响应 ID 和用量。不要公开 8000 端口，不要提交密钥。Codespaces 的计算资源和 DeepSeek 费用分别由账号承担；不用时停止 Codespace。

## Windows 一键本地启动

下载开发分支 ZIP，解压。在 Docker Desktop 已启动时，双击 start-flowpilot.cmd。默认复制 .env.example 并使用 Mock。真实模型需要在本地 .env 中填写 AI_PROVIDER=deepseek 和 DEEPSEEK_API_KEY，保存后再次双击启动。脚本打开 http://127.0.0.1:8000/console/。双击 stop-flowpilot.cmd 可停止服务并保留数据。首次构建需要网络。

手动等效命令：docker compose -p flowpilot-quick -f compose.quick.yml up --build -d --wait

以上两种都是实际 Vue、FastAPI、LangGraph、SQLite 和业务工具，不是 GitHub Pages 静态模拟。快速版不启动 PostgreSQL、ClickHouse、Redis 和对象存储服务；完整基础设施仍使用 docker-compose.yml。两个部署分别保存数据；同时使用需处理 8000 端口冲突。

## 验收顺序

先验证普通营销名单交付，再验证 A/B 双臂及排重；客服验证当前会员查询、跨会员查询拒绝及确认工单。真实模型模式需检查候选 generation_receipt 与客服 model_tool_round，模型本身不是免费或 CI 中默认运行。自动化验收见 Actions 的 vue、quick-compose 和 compose 作业。Codespaces 实例仍需用户亲自创建，未在 CI 中实际创建云端实例。
